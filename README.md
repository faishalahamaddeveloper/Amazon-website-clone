# 🛒 Amazon Website Clone

A responsive front-end clone of the Amazon e-commerce homepage built to practice modern web design and layout structuring.

## ✨ Features
- **Navigation Bar:** Includes the Amazon logo, delivery location selector, interactive search bar, language option, sign-in menu, and shopping cart icon.
- **Hero Section:** Full-width promotional banner with quick access links.
- **Product Categories Grid:** Multi-column product cards featuring electronics, fashion, home essentials, and daily deals.
- **Footer Section:** Clean, structured multi-column footer with "Back to Top" navigation and standard Amazon links.

## 🛠️ Technologies Used
- **HTML5** – Page structure and semantic layout
- **CSS3** – Styling, Flexbox, and CSS Grid

## 🚀 How to View Locally
1. Clone or download this repository to your computer.
2. Open the `index.html` file in any web browser (Chrome, Edge, Firefox, etc.).
